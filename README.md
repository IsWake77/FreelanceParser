# Фриланс-парсер заказов

Собирает заказы с **Kwork, FL.ru, Freelance.ru, Workzilla, Profi.ru** по твоему
профилю (телеграм-боты, Mini Apps, SaaS, веб-приложения, сайты, API, бэкенд,
автоматизация) и складывает их в `orders.json` и `orders.csv`.

Парсер — на чистой стандартной библиотеке Python. Для Telegram-бота ставится
одна библиотека: `pip install python-telegram-bot` (уже установлена).

## Запуск

```bat
cd c:\Users\fento\Desktop\pats\parser
python main.py          :: один проход
python main.py --loop   :: цикл, проверка каждые 10 минут (interval_minutes)
python bot.py           :: Telegram-бот с кнопками (см. ниже)
```

## Telegram-бот

### Настройка (один раз)

1. В Telegram у **@BotFather**: `/newbot` → имя → получишь токен
   вида `123456789:AA...`.
2. Впиши токен в `config.json`:
   ```json
   "telegram": { "bot_token": "123456789:AA...", "admin_ids": [], "auto_chats": [] }
   ```
   (или запусти бота и отправь ему `/token <токен>`, потом перезапусти).
3. `python bot.py` — бот запущен.
4. Напиши боту `/start` — первый, кто это сделал, становится владельцем
   (bot_token секретен, так что это будешь ты).

### Кнопки в боте

| Кнопка | Что делает |
|---|---|
| 🔍 Проверить сейчас | запускает сбор по всем включённым источникам, шлёт карточки новых заказов |
| 🤖 Автопроверка вкл/выкл | фоновый цикл: новые заказы приходят пушем каждые `interval_minutes` |
| ⭐ Избранное | список заказов, отмеченных звёздочкой (хранится в `favorites.json`) |
| 📋 Последние | последние 15 заказов из базы, даже если они не новые |
| 📊 Статистика | сколько заказов в базе по площадкам + последний найденный |
| ⚙️ Настройки → Kwork / FL.ru / … | включить/выключить площадку прямо из Telegram |
| ⚙️ Настройки → ⏱ Интервал | 5 / 10 / 15 / 30 / 60 минут |
| ⚙️ Настройки → 🔑 Ключевые слова | показать список, добавить/удалить слова («бот*» — стем) |

На каждой карточке заказа:

- **⭐ В избранное / ✅ В избранном** — добавить/убрать заказ (повторное
  нажатие снимает отметку);
- **🔗 Открыть** — ссылка на биржу;
- **🏠 Меню** — вернуться в главное меню (также кнопка 🏠 есть в сводке
  проверки, «Последних» и «Избранном» — `/start` каждый раз не нужен);
- **⏱ Работа: ~N–M ч** — ИИ-оценка времени на заказ. По умолчанию работает
  встроенный анализатор (`estimator.py`: тип задачи × модификаторы сложности).
  Если вписать `openai_api_key` в `config.json`, оценку будет давать
  gpt-4o-mini (кэшируется в `estimates.json`, при ошибке — откат к эвристике).

Бот приватный: кнопки работают только у владельца (`telegram.admin_ids`).
Настройки, изменённые в боте, сохраняются в тот же `config.json` — консольный
`python main.py` подхватит их автоматически.

Результаты:

| Файл | Что внутри |
|---|---|
| `orders.json` | все заказы с дедупликацией между запусками |
| `orders.csv`  | то же для Excel (utf-8-sig, дописывается) |

Колонки CSV: `found_at, source, title, price, url, date, category, responses, description`.

## Структура кода

| Файл | За что отвечает |
|---|---|
| `main.py` | консольная точка входа: загрузка конфига, один цикл сбора, вывод свежих заказов в терминал |
| `bot.py` | Telegram-бот (python-telegram-bot v22): меню с inline-кнопками, автопроверка по таймеру, избранное, настройка источников/интервала/ключевых слов прямо из чата. Власть только у первого `/start` (`admin_ids`) |
| `core.py` | сердце парсера: `run_cycle()` прогоняет все включённые источники, чистит HTML из текстов (`clean_text`), фильтрует, дедуплицирует через хранилище и возвращает только новые заказы |
| `sources/` | по одному адаптеру на площадку, у каждого свой `fetch(config)`: |
| `sources/kwork.py` | AJAX `POST /projects` → JSON с ценой и датой (щадящий rate-limit) |
| `sources/flru.py` | RSS-лента FL.ru (без цен) |
| `sources/freelanceru.py` | HTML-парсинг категорий «Веб-разработка и IT» и «ИИ» |
| `sources/workzilla.py` | HTML `/quests`, требует cookies из браузера (выключен по умолчанию) |
| `sources/profiru.py` | `/orders`, обходит антибот только с cookies (выключен по умолчанию) |
| `sources/base.py` | общий HTTP-клиент с ретраями, таймаутами и поддержкой raw-cookie |
| `filters.py` | `KeywordFilter`: стемы (`бот*` → «бота/боты/ботов»), составные фразы, исключения (отзывы, упоминания), `min_matches` |
| `storage.py` | `OrderStore`: дедупликация по URL между запусками, запись `orders.json` + `orders.csv` (utf-8-sig для Excel) |
| `favorites.py` | избранное бота: `favorites.json`, короткий md5-хэш от URL используется в callback-кнопках |
| `estimator.py` | ИИ-оценка времени на заказ: эвристика (тип задачи × модификаторы сложности) + опционально gpt-4o-mini по `openai_api_key`, кэш в `estimates.json` |

Поток данных: `sources/*.fetch()` → `core.clean_text()` → `filters.KeywordFilter` → `storage.OrderStore` (дедуп) → `bot.send_orders()` (карточки с ⭐/🔗/🏠 и ⏱-оценкой).

Свой источник = один файл в `sources/` с функцией `fetch(config)`, возвращающей список словарей `{source, title, url, price, date, category, description, responses}`, плюс строка в `SOURCES` в `core.py`.

## Как это работает

1. Каждый включённый источник отдаёт свежие заказы (см. таблицу ниже).
2. Фильтр `filters.py` отбирает заказы по `keywords` из `config.json`
   (стемы: `бот*` найдёт «бота/боты/ботов»; `exclude_keywords` отсекает мусор
   типа «написание отзывов»).
3. Новые заказы дописываются в файлы и печатаются в консоль.

| Источник | Способ | Замечания |
|---|---|---|
| FL.ru | RSS `rss/all.xml?category=5` (Программирование) | цену RSS не отдаёт |
| Kwork | AJAX `POST /projects`, JSON с ценой и датой | **щадящий rate-limit**: пауза `pause_seconds`; при 403 — попробуйте позже |
| Freelance.ru | HTML `/task?c[]=4` (Веб-разработка и IT), `c[]=724` (ИИ) | |
| Workzilla | HTML `/quests` + cookie из браузера | выключен по умолчанию |
| Profi.ru | HTML `/orders` + cookie (лучший результат) | антибот; выключен по умолчанию |

## Настройка (config.json)

- `keywords` / `exclude_keywords` / `min_matches` — фильтр.
- `interval_minutes` — период цикла в `--loop`.
- `sources.<имя>.enabled` — вкл/выкл площадку.
- `sources.kwork.categories` — id категорий Kwork
  (`kwork.ru/projects?c=<id>`; 11 — Боты и чаты, 45 — Разработка,
  85 — Создание сайтов). Пустой список `[]` — вся лента (фильтр по словам
  всё равно отберёт нужное).

### Workzilla: как включить

Гостям список заданий скрыт. Включи браузерную сессию:

1. Войди на workzilla.com в браузере.
2. `F12 → Network → обнови страницу → клик на первый запрос к workzilla.com
   → Headers → Request Headers → cookie` — скопируй всю строку.
3. Вставь её в `config.json → sources.workzilla.cookies` и поставь
   `"enabled": true`.

### Profi.ru

Площадка блокирует программные клиенты и скрывает заявки за подпиской.
Адаптер пробует страницу заявок с твоими cookies
(`sources.profi.cookies`, включается так же, как Workzilla). Если профит от
Profi.ru нужен стабильно — самый надёжный путь это расширение браузера или
Playwright с живым профилем, скажи, добавлю.

## Советы

- Не ставь `pause_seconds` в Kwork ниже 5-6 сек — словишь 403 not_access на
  несколько часов.
- Запускай через планировщик Windows (taskschd) вместо `--loop`, если удобнее:
  `python main.py` раз в 10 минут, дедупликация сама исключит повторы.
